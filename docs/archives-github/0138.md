## Contexte
Décision de Maxou : chat **restreint** pour l'instant, uniquement les émotes historiques et les phrases toutes faites validées dans #132. Pas de texte libre.

## Objectif
Pouvoir se chambrer et s'encourager dans le salon (et pendant la partie, en petit), sans aucun risque de message déplacé.

## Tâche pour l'agent
1. Panneau d'émotes et de phrases dans le salon ; bulles qui apparaissent quelques secondes près du joueur et dans un petit fil récent.
2. Pendant la partie : émotes seulement, discrètes, sans masquer la frise.
3. Le client n'envoie qu'un **identifiant** du catalogue ; le serveur (ou le canal) refuse tout le reste. Limite anti-spam (par ex. 1 message / seconde, 5 / 10 s).
4. Bouton « masquer ce joueur » (local).

## Avant de commencer
- Lire `CLAUDE.md`, `docs/multijoueur.md`. Un point flou : **poser la question à l'humain** avant de coder.
- **Suivre les maquettes validées de #131** ; tout élément visuel absent est d'abord montré **en images dans la conversation**.
- PC et téléphone.
