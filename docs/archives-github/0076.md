## Avant
Sur l'accueil, « Mode inversé » était grisé (« Bientôt »). Le moteur existait côté serveur (2.3) mais aucun écran ne permettait d'y jouer, et une partie inversée affichait « Ce mode n'a pas encore d'écran de jeu ».

## Après
- L'accueil ouvre `/inverse` : deux onglets, **Solo libre** (général, période, pack, thème) et **Solo scolaire** (niveau, chapitres), avec les mêmes filtres et la même difficulté que le solo. Le choix porte `sens=inverse`.
- Écran de partie inversé, plein écran comme les autres : la date est affichée en grand et marquée sur la frise, un champ texte reçoit l'événement, Entrée valide, le chrono du serveur tourne.
- Correction : bonne réponse ou non, titre attendu, description, points. La frise se recentre sur la date.
- Aucune suggestion ni correction automatique dans le champ (le titre attendu n'arrive qu'après la réponse).
- Le bilan indique pour chaque question si c'était juste et ce que le joueur avait écrit.
- Aucune migration : le moteur 2.3 est déjà en base.

## Comment tester
1. Ouvrir l'aperçu Vercel de cette PR, cliquer sur « Mode inversé » depuis l'accueil.
2. Choisir « Solo libre », « Général », « Facile », puis Jouer.
3. Écrire un événement (ex. « guerre froide » pour 1947), appuyer sur Entrée : la correction s'affiche avec le titre attendu et les points.
4. Laisser le chrono tomber à zéro sur une question : elle vaut 0 point.
5. Aller au bout des 10 questions : le bilan s'affiche, « Rejouer » relance une partie inversée.
6. Refaire un essai via l'onglet « Solo scolaire ».
