## Avant
À la fusion d'une PR, il fallait qu'un agent pense à retirer le label `en cours` et le 🚧, puis à cocher l'étape dans #31. Si Maxou ou Antonin fusionnait seul, #31 restait en retard.

## Après
Un robot GitHub (`.github/workflows/suivi-issue.yml`) s'exécute à chaque fusion sur `main`. Pour chaque `Closes #N` de la PR, il retire le label `en cours`, enlève le 🚧 du titre, puis coche la ligne `#N` dans #31 et y ajoute `(PR #…)`. Une PR sans `Closes` (lot intermédiaire) ne change rien. La date de mise à jour et la note sur la base KFFR restent à l'agent. `CLAUDE.md` le précise.
