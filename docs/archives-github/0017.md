> **Décision de Maxou (7 octobre 2026)** : pas de calendrier, pas de champ unique. On répond avec les trois cases jour, mois, année de la charte (seules les cases utiles à la difficulté), ou en plaçant le curseur sur la frise. Cases et frise se répondent dans les deux sens : ce qu'on tape place le losange, ce qu'on pointe remplit les cases.

## Objectif
Une saisie rapide, utilisable sous chrono de 30 secondes.

## Critères d'acceptation
- [ ] Tests unitaires de la lecture des cases (précisions, av. J.-C., valeurs impossibles)
- [ ] Taper dans les cases place la réponse sur la frise, pointer la frise remplit les cases
- [ ] Une réponse se donne en moins de 5 secondes
- [ ] Lint, types, build verts
