## Contexte
Mode pédagogique (PRD) : « Découvrir » montre une frise du chapitre avec de petites cartes cliquables, chacune donnant une explication pour réviser. Le PRD prévoit que ces cartes soient rédigées par un agent IA. Les chapitres viennent de `content/dataset-v18/kiffeurs-themes-v18.csv` et les événements liés de `kiffeurs-curriculum-links-v18.csv`.

## Objectif
Chaque chapitre a 5 à 12 cartes justes, au bon niveau, prêtes à être posées sur la frise.

## Tâche pour l'agent
Lis `docs/prd.md` (Mode pédagogique), `content/README.md` et les libellés officiels (`official_wording`) dans `kiffeurs-curriculum-links-v18.csv`.
1. Pour chaque chapitre, rédige des cartes : `chapter_id`, `event_id` (ou période début/fin pour une carte de contexte), titre, texte de 60 à 120 mots, « à retenir » en une phrase, notions clés.
2. Niveau de langue adapté au niveau scolaire du chapitre ; aucune invention de date : les dates viennent du dataset.
3. Écris `content/pedagogie/cartes-v1.csv` et un script ou une étape du script d'import (1.2) qui charge les cartes dans une table `histoire.chapter_cards` (migration incluse, lecture publique : les cartes ne servent pas de questions).
4. Liste en fin de PR les chapitres où le contenu du dataset ne suffit pas.
