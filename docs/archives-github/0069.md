Closes #19

## Avant
La page d'accueil affichait une liste de test d'événements. Pour jouer, il fallait passer par `/partie/nouvelle`, qui lançait toujours la même partie générale.

## Après
- **Accueil** : quatre grandes entrées. Les trois premières sont Solo libre, Solo scolaire et Apprendre ; la quatrième, Mode inversé, est marquée « Bientôt » en attendant la 3.6. Sans compte, un bouton « Se connecter » s'affiche.
- **/solo** : on choisit d'abord ce qu'on joue.
  - Général.
  - Période : six périodes, ou une période libre avec ses années.
  - Pack : les 24 packs prêts à jouer.
  - Thème : 42 thèmes ayant au moins 10 événements.
  
  On choisit ensuite la difficulté, puis « Jouer ». Une difficulté sans assez de questions est grisée. Le pack « Époque napoléonienne » n'a que 4 événements jouables : il est affiché avec « pas encore assez de questions ».
- **/scolaire** : on choisit le niveau (10 niveaux), puis les chapitres à cocher, tous cochés par défaut. La difficulté « Facile » est proposée par défaut.
- Le dernier choix est mémorisé dans le navigateur. « Rejouer » relance le même choix.
- Le choix est revérifié côté serveur avant d'appeler `start_game`. Si la base répond « pas assez de questions », un message clair s'affiche.

Les listes (packs, thèmes, périodes, chapitres) sont générées depuis le dataset v18 par `npm run content:catalogue-solo`. Elles ne demandent donc aucune requête à l'affichage, comme `/apprendre`. Les identifiants ont été vérifiés sur KFFR : 24 packs actifs, 42 thèmes, 41 chapitres. **Aucune migration.**

## Comment tester
Sur l'aperçu Vercel :
1. Sur `/`, les 4 entrées s'affichent ; Mode inversé est marqué « Bientôt ».
2. Sur `/solo`, choisis l'onglet Pack, puis « France », puis Facile, puis **Jouer**. Une vraie partie de 10 questions doit démarrer.
3. Reviens sur `/solo` : « France » est resté choisi. Essaie aussi Période → XIXe siècle → Difficile, et Thème → Sport.
4. Sur `/scolaire`, choisis 3e, garde les chapitres cochés, puis **Jouer**. Une partie doit démarrer.
5. Au bilan, **Rejouer** relance le même mode.
6. Sur téléphone (375 px), tout reste lisible et le bouton Jouer reste collé en bas.
