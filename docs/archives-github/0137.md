## Contexte
Un salon peut être **ouvert** : il apparaît alors dans un menu « Parties ouvertes » où d'autres joueurs (avec compte) viennent le compléter. Les autres entrent par le code JJ/MM/AAAA ou le lien (invités compris). Décisions dans #130.

## Objectif
Trouver une partie en deux clics, ou entrer un code aussi vite qu'une date en partie.

## Tâche pour l'agent
1. Entrée « Jouer à plusieurs » depuis l'accueil : Créer un salon / Rejoindre avec un code / Parties ouvertes.
2. **Rejoindre avec un code** : les 3 cases JJ / MM / AAAA du jeu (mêmes composants et mêmes corrections qu'en partie), pavé numérique sur téléphone, message clair si le code n'existe pas ou si le salon est plein.
3. **Parties ouvertes** (comptes seulement) : liste en direct des salons ouverts en attente (nom de l'hôte, mode, contenu, places libres), bouton Rejoindre. On ne rejoint pas une partie déjà lancée : le salon montre « partie en cours » et on attend la suivante dans le salon.
4. Lien d'invitation `/salon/<code>` : ouvre directement le salon (pseudo temporaire pour un invité, #134).

## Avant de commencer
- Lire `CLAUDE.md`, `docs/prd.md` (multijoueur), `docs/multijoueur.md`, la doc Next.js 16. Un point flou : **poser la question à l'humain** avant de coder.
- **Suivre les maquettes validées de #131** ; tout élément visuel absent est d'abord montré **en images dans la conversation**.
- PC et téléphone, sans défilement.

- [ ] Invité absent de la liste des parties ouvertes (refus côté serveur)
