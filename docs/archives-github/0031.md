**Comment s'en servir** : prendre une issue dont toutes les dépendances sont fermées **et qui n'est pas marquée `en cours`**, poser le label `en cours` et s'assigner l'issue, la confier à un agent (Claude Code ou autre) sur une branche `issue-<numéro>`, relire la PR, fusionner, puis retirer le label. Les étapes d'une même ligne « en parallèle » peuvent avancer en même temps, une chez Maxou, une chez Antonin. Règle complète : section « Traiter une issue » de `CLAUDE.md`.

**Tenir cette liste à jour** : cocher une étape quand son issue est fermée (PR fusionnée), mettre 🚧 devant celles qui portent le label `en cours`, et le retirer à la fusion. La liste ne se coche pas toute seule : c'est un geste à faire (ou à demander à l'agent) à chaque fusion.
