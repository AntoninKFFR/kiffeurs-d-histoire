## Contexte
Le mode inversé accepte une réponse si elle ressemble au titre ou à une variante acceptée (« Guerre froide » pour « La guerre froide »). 394 des 507 événements scolaires de `content/dataset-v18/kiffeurs-events-v18.csv` n'ont aucune variante (colonne `aliases` vide).

## Objectif
Chaque événement scolaire jouable a 2 à 5 variantes de titres qu'un élève pourrait raisonnablement écrire.

## Tâche pour l'agent
Lis `docs/prd.md` (Mode inversé) et `content/README.md`.
1. Pour chaque ligne de `kiffeurs-events-v18.csv` avec `levels_seen` non vide, `playable=TRUE` et `aliases` vide, propose 2 à 5 variantes : nom court usuel, nom sans article, nom courant utilisé en classe. Pas de variantes trop vagues (« la guerre », « le traité »).
2. Vérifie qu'aucune variante ne correspond à un autre événement (comparaison après minuscules, sans accents, sans article, comme `histoire.normalize_answer`).
3. Écris le résultat dans `content/dataset-v18/kiffeurs-alias-additions-v18.csv` avec les colonnes `event_id,title_canonical,aliases_added,justification`, sans modifier les fichiers d'Antonin.
4. Mets à jour le script d'import (1.2) pour fusionner ce fichier s'il est déjà mergé ; sinon décris la fusion dans la PR.

## Critères d'acceptation
- [ ] 394 événements couverts, 0 collision d'alias
- [ ] Antonin a relu un échantillon d'au moins 50 lignes
