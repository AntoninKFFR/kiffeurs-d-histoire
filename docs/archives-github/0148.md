Toutes les étapes de la V1.3, **entièrement consacrée au multijoueur**, décidée par Maxou le 21 oct. 2026 (la V1.2 est l'enrichissement du catalogue, #122). Les règles de jeu décidées sont dans #130 (puis dans `docs/prd.md` une fois #130 fusionnée). Même fonctionnement que la V1 (#31) et la V1.1 (#98) : chaque étape est une issue rédigée pour être confiée à un agent IA (section « Tâche pour l'agent ») et vérifiée par un humain (critères d'acceptation).

**Comment s'en servir** : prendre une issue dont toutes les dépendances sont fermées **et qui n'est pas marquée `en cours`**, poser le label `en cours` et s'assigner l'issue, la confier à un agent sur une branche `issue-<numéro>-…`, relire la PR, fusionner. Règle complète : section « Traiter une issue » de `CLAUDE.md`. Tant que #130 n'est pas fusionnée, le robot ne coche pas cette liste : la cocher à la main à chaque fusion.

**Trois règles propres à la V1.3**
- **Visuel d'abord** : toute image, maquette ou proposition visuelle est montrée **en images dans la conversation** et validée par Maxou **avant** de coder (#131 pour les écrans, #132 pour les émotes).
- **Un doute, on demande** : l'agent pose ses questions à l'humain (conversation ou commentaire de l'issue) plutôt que d'inventer une règle de jeu.
- **Infrastructure de KFFR contrée** (décision de Maxou et d'Antonin, 22 oct.) : les amis, la présence et les invitations sont **ceux de la contrée**, avec une seule liste d'amis pour les deux jeux. Antonin les ouvre à Histoire dans son dépôt (#149). Les salons et les parties restent dans `histoire`, avec du code copié et adapté de la contrée. On n'écrit jamais dans `public` depuis ce dépôt.

Légende : 🧑 humain · 🤖 agent code · ✍️ agent contenu (LLM) · 🚧 en cours (label `en cours`)
