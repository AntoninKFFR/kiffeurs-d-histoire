## Contexte
Le cœur du multi. Décisions de Maxou (#130) : questions de date avec précision Année / Mois / Jour réglable, questions « période » si l'hôte les active, **pas de mode inversé** ; chrono 30 s ; dès que tous ont validé, on passe à la révélation ; même calcul de score qu'en solo, points cumulés ; **mode chrono** optionnel (après la première réponse, il reste 10 s aux autres).

## Objectif
Tous les joueurs voient la même question au même moment, répondent sur la frise comme en solo, et le serveur arbitre.

## Tâche pour l'agent
1. Lancement par l'hôte : RPC qui tire les questions selon les réglages (réutiliser le tirage solo et les filtres existants), crée la partie et diffuse la première question.
2. Écran de partie multi : réutiliser la frise plein écran et la saisie (clic + cases JJ/MM/AAAA) du solo ; indicateur « X a validé » sans dévoiler la réponse.
3. Réponse via RPC avec horodatage serveur ; refus après la deadline ; fin de question quand tous ont validé ou à la deadline.
4. Mode chrono : `deadline = least(deadline, première réponse + 10 s)`, annoncé visuellement.
5. Score : même fonction SQL qu'en solo ; un joueur déconnecté marque 0 à la question manquée.
6. Brancher sur l'étape suivante (révélation, #142) avec un événement « question close ».
