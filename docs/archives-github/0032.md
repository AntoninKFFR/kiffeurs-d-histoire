Before: le site gardait le style par défaut de Next.js (fond blanc, police Geist) et n'avait aucun écran de jeu.

After: tout le site prend les couleurs et les polices de la charte « Cabinet de curiosités ». La page `/apercu` montre l'écran de partie de la maquette n° 4 avec une question de démonstration (Prise de la Bastille) : frise zoomable jusqu'au jour avec décor par époque, saisie jour / mois / année avec saut automatique, bande des époques, correction avec score. Un sélecteur en haut change la précision demandée (année, mois, jour).

La date attendue reste côté serveur : la page reçoit la question sans la réponse, et la correction passe par une server action. Les vraies questions suivront le même chemin, avec la correction en SQL `security definer`.

How : jetons de couleur et polices dans `globals.css` (Tailwind 4, classes `bg-encre`, `text-oxyde`, `font-date`…) et `layout.tsx` (`next/font`). Les motifs sont dans `public/motifs.svg`. Les calculs de la frise, sans DOM, sont dans `src/lib/game/frise.ts`. Les composants sont dans `src/components/partie/`. Les pages d'accueil et de connexion ne sont pas retouchées, pour ne pas entrer en conflit avec #1 ; elles héritent seulement du fond et des polices.

Vérifié : lint, types et build passent ; parcours testé dans Chromium (14/07/1789, mars 1515, -52, vider les cases, clic, molette, largeur téléphone sans défilement horizontal).
