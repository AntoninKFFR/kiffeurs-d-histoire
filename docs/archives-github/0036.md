## Après
Une commande charge (ou recharge) tout le dataset dans le schéma `histoire`, sur n'importe quelle base :

```bash
npm run content:import -- --dossier content/dataset-v18
```

Un tableau récapitule créés / mis à jour / retirés / ignorés.

- Upserts idempotents : la deuxième exécution donne 0 création et les mêmes totaux.

- Les 113 lignes du programme sans événement rattaché sont ignorées (comptées dans le résumé) ; les identifiants fusionnés (`event-redirects`) sont remplacés par l'identifiant canonique.
