## Contexte
Chaque événement s'affiche avec une petite illustration sur la frise et au format carte. Les fichiers vont dans Supabase Storage et sont servis par CDN (voir `docs/architecture.md` §5).

## Objectif
Tous les événements des packs « 50 dates incontournables » et « 100 dates incontournables » ont une illustration dessinée ; les autres événements (dont les événements scolaires) affichent un pictogramme de leur thème. *(Découpage décidé avec Maxou le 6 oct. 2026 : un dessin unique par événement scolaire serait trop lourd à produire ; ils pourront être illustrés dans une issue ultérieure.)*

## Tâche pour l'agent
Lis la décision de l'étape 1.6 dans `docs/prd.md`.
1. Produis ou récupère les illustrations selon le style et le format décidés, nommées `<event_id>.<ext>`.
2. Pour les images libres de droit, tiens un fichier `content/illustrations/licences.csv` (`event_id,url_source,auteur,licence`).
3. Écris `scripts/upload-illustrations.ts` qui envoie les fichiers dans un bucket Storage `histoire-illustrations` et renseigne le chemin dans la base.
4. Prévois un pictogramme par grand thème pour les événements sans illustration.

## Critères d'acceptation
- [x] Packs « 50 » et « 100 dates » illustrés (100 dessins, PR #41, #43 et #46)
- [x] Un pictogramme par grand thème pour les autres événements (déjà fournis par la charte : `public/motifs.svg`)
- [x] Chaque image respecte le poids maximal décidé (8 Ko, contrôlé par `scripts/verifier-illustrations.py`)
- [x] Licences tracées pour toute image externe (aucune image externe : dessins originaux)
- [x] Envoi en base de production : 100 événements avec `image_path` et 100 SVG dans le bucket public `histoire-illustrations` sur KFFR (7 oct. 2026)
