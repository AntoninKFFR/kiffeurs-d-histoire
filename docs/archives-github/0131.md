**Dépend de** : rien (lire les décisions de [V1.3 · 0.1] #130). **Bloque** : toutes les issues d'écran (phases 2 à 5)

## Contexte
Règle de Maxou : on s'aligne sur le visuel **avant** de coder, pour aller plus vite et consommer moins. Les maquettes se montrent **en images dans la conversation** (fichiers PNG), jamais en lien d'aperçu ni en code à relire. Principe d'écran : c'est une **app de jeu** ; la frise est le cœur, plein écran, tout tient sans défiler, rien de tassé. Charte « Cabinet de curiosités » (lien dans `CLAUDE.md`).

## Objectif
Un jeu de maquettes validé qui sert de référence à toutes les issues V1.3.

## Tâche pour l'agent
1. Produire des images PC (1366×768) **et** téléphone (paysage 667×375 et portrait) pour :
   - accueil multi : « Créer un salon », « Rejoindre avec un code » (saisie JJ/MM/AAAA en 3 cases comme en partie), « Parties ouvertes », amis en ligne ;
   - salon : joueurs (couronne d'hôte, invités marqués), code et lien à partager, réglages de l'hôte, chat d'émotes et de phrases, bouton Lancer ;
   - partie Convivial : frise plein écran, classement posé sur le côté, curseurs des autres (mode visible), chrono, indicateur « X a validé » ;
   - révélation : placements de tous sur la frise, puis bonne date, puis classement qui bouge ;
   - fin : podium, puis retour au salon ;
   - vote (3 propositions) et roulette Mystère ;
   - 1 contre 1 : écran de pick & ban (7 propositions, bannissements alternés) ;
   - amis : liste, statut, invitation reçue.
2. Proposer 2 variantes quand un choix est ouvert, les montrer dans la conversation, recueillir les retours, itérer.
3. Ranger les images validées dans `docs/maquettes/v1.3/` et les lister dans `docs/multijoueur.md`.

## Partie humaine
- [ ] Maxou valide chaque écran (ou demande des changements) dans la conversation

## Critères d'acceptation
- [ ] Tous les écrans listés validés par Maxou, PC et téléphone
- [ ] Images validées commitées dans `docs/maquettes/v1.3/`, aucune ligne de code de jeu
