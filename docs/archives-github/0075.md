## Objectif
L'ambiance colle au sujet de la partie, change rarement, et ne gêne jamais.

## Règle de choix : une ambiance par partie, pas par question
1. Chaque événement du lot reçoit une ambiance (règle de classement ci-dessous).
2. Si presque tous les événements (seuil de départ : 80 %) ont la même ambiance → cette ambiance. Sinon (lot mélangé) → `neutre`.
3. Accueil, menus, bilans → `neutre`.
4. Mode scolaire et `/apprendre` : ambiance du chapitre (ex. chapitre sur les guerres mondiales → `guerre-1939-1945` ou `guerre-1914-1918` selon dominante).
Variante à discuter dans la PR : passer en ambiance de guerre seulement le temps d'une bataille dans un lot mixte, si le fondu reste agréable.

## Règle de classement d'un événement
Dans cet ordre de priorité :
1. **Guerre** : étiquettes « Guerres et conflits » ou « Batailles et opérations », puis l'ambiance de guerre de l'époque (jusqu'en 1491 → `guerre-ancienne` ; 1492-1914 → `guerre-moderne` ; 1914-1918 ou contexte « Première Guerre mondiale » → `guerre-1914-1918` ; 1939-1945 ou contexte « Seconde Guerre mondiale » → `guerre-1939-1945` ; après 1945 → `guerre-depuis-1945`). Bornes à relire avec Maxou et Antonin.
2. **Lieu pour l'Antiquité** : Grèce → `grece` ; Italie/Rome → `rome` ; Mésopotamie, Égypte, Orient, Asie, Préhistoire → `prehistoire-origines`.
3. **Époque** : 476-1491 `moyen-age` ; 1492-1788 `renaissance-lumieres` ; 1789-1814 `revolution-empire` ; 1815-1913 `xixe` ; 1946-1991 `guerre-froide` ; 1918-1938 et après 1991 `contemporain`.
4. Non classable (date inconnue) → `neutre`.
