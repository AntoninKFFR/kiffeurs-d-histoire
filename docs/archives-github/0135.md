## Objectif
Une couche temps réel réutilisable par tous les écrans multi, avec un objectif mesuré : **moins de 0,2 s** entre l'action d'un joueur et son affichage chez les autres.

## Tâche pour l'agent
1. Module client `src/lib/multi/` : un seul canal par salon (Presence pour qui est là, Broadcast pour les événements), typé, avec réabonnement automatique.

3. Affichage **optimiste** : le clic d'un joueur s'affiche tout de suite chez lui, le serveur confirme ensuite.
4. **Reconnexion** : 30 s pour revenir à sa place (mêmes points) ; au-delà, retiré du salon.
5. Page de test interne (non liée dans le menu) qui affiche la latence mesurée entre deux onglets ; noter les mesures dans `docs/multijoueur.md`.
