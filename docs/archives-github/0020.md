## Contexte
Mode inversé (PRD) : le jeu donne une date et la montre sur la frise, le joueur écrit l'événement. Mêmes filtres que le solo libre ou le solo scolaire, même chrono.

## Objectif
Le mode inversé se joue depuis l'accueil avec l'écran de partie existant.

## Tâche pour l'agent
Lis `CLAUDE.md`, `docs/prd.md` et le travail des étapes 2.3 et 3.4.
1. Entrée « Mode inversé » de l'accueil → choix des filtres (réutilise les écrans de 3.5) avec `sens = inverse`.
2. Variante de l'écran de partie : date affichée en grand et sur la frise, champ texte, Entrée valide.
3. Correction : bonne réponse ou non, titre attendu, description, points.
4. Ne jamais proposer d'autocomplétion qui révélerait les titres.
